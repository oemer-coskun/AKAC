# AKAC 0.4 draft: destination profiles and run result limits

Status: draft requirements for the AKAC 0.4 profile, to be merged into
`spec/AKAC-0.4.md`. Not a ratified external standard; no external review has
taken place. MUST, SHOULD and MAY retain their RFC 2119/8174 meanings.
Decision: [ADR-008](../../governance/ADR-008-destinations.md).
Integration contract: [docs/INTEGRATIONS.md](../../docs/INTEGRATIONS.md).
Conformance evidence: `conformance/vectors-destinations.json` (profile
`AKAC-Destinations/0.4-draft`, run by `conformance/run-destinations.ts`),
`tests/destinations.test.ts`, `tests/destinations-postgres.test.ts`.

## Threats addressed

- Sensitive information disclosure to model providers, tools and external
  services (OWASP Top 10 for LLM Applications 2025, LLM02; excessive agency,
  LLM06): reading a document does not authorize sending it anywhere (0.1 R10).
- Zero-trust egress (NIST SP 800-207): every release is authorized per request
  against the receiving destination, not against network location.

## Model

A *Destination* is a tenant-scoped record `{id, tenant, class, maxClassification,
purposes, active}`. `class` is one of `internal-user`, `internal-service`,
`model-provider`, `tool`, `external`. A principal MAY reference one through
`Actor.destination`. A grant MAY carry `destinations` (classes or Destination
ids) and `maxResults` (1..64).

## Requirements

**R-DEST-1 — Tenant scope.** Destinations MUST be keyed by (tenant, id); a
record of another tenant MUST be indistinguishable from an absent one. A
Destination id MUST NOT equal a class name.

**R-DEST-2 — Target of a release.** The destination of a share/export is: the
recipient's Destination record when `Actor.destination` is present; otherwise
the implicit class `internal-user` for a principal of kind `user`; otherwise
none.

**R-DEST-3 — Profile gate.** When the recipient references a Destination, the
release MUST be denied unless the record exists in the binding's tenant, is
active and well-formed, the highest transitive effective classification (R25)
of everything released is at most `maxClassification`, and the context purpose
is in `purposes`. An unknown, inactive, foreign or malformed profile denies.

**R-DEST-4 — Run restriction.** When the grant carries `destinations`, the
release MUST be denied unless the destination's class or id is listed; a
recipient without a destination (R-DEST-2 "none") is denied; the implicit
`internal-user` destination matches the class `internal-user` only.

**R-DEST-5 — Legacy behaviour.** Without `Actor.destination` and without
`Grant.destinations`, releases MUST behave exactly as in 0.3.

**R-DEST-6 — Only narrowing.** R-DEST-3 and R-DEST-4 add conditions to the 0.3
recipient checks and MUST NOT allow any release those checks deny.

**R-DEST-7 — Obligation.** An allowed release governed by a Destination MUST
carry `destination_restricted` with the destination class and id; one to the
implicit `internal-user` under a restricted run carries `["internal-user"]`. If
the intersection with another `destination_restricted` obligation is empty, the
release MUST be denied.

**R-DEST-8 — Read-only evaluation.** A read-only evaluation (Engine.evaluate,
the AuthZEN `context.destination` member) for share/export that names a
Destination MUST apply R-DEST-3 and R-DEST-4. One that names none, under a
restricted run, MUST be allowed only with `destination_restricted` listing the
run's destinations; the enforcement point MUST then send only there.

**R-DEST-9 — Attenuation.** A child grant of a parent with `destinations` MUST
carry `destinations` that are a subset of the parent's; a child of a parent
with `maxResults` MUST carry `maxResults` not greater than the parent's.
Violations deny with `INVALID_DELEGATION`.

**R-DEST-10 — Result limit.** With `maxResults`, one openContext MUST NOT
disclose more distinct documents than `maxResults` (deny `OUT_OF_SCOPE`), and
retrieval MUST cap its result limit at `maxResults`.

**R-DEST-11 — Enforcement boundary.** AKAC decides; transport is enforced by the
integration (egress proxy, gateway, runtime). A policy enforcement point that
cannot keep content to the destination named by `destination_restricted` MUST
treat the decision as a deny (R-DE-7). AKAC makes no claim of enforcing egress
by itself.

**R-DEST-12 — Administration.** Destination changes MUST be security-admin
operations, audited, and an update MUST advance the tenant epoch.

Denials of R-DEST-3/4/7/8 use the existing reason code `RECIPIENT`; public
responses stay non-distinguishing.
